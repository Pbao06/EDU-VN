SYSTEM FLOW (UPDATED - Multiple Learning Paths)
-----------
1. User đăng ký → Login → Nhận JWT token
2. User làm Onboarding → Cập nhật UserType, MainGoal, FieldId
3. User làm Recommendation Quiz (theo FieldId của user):
   - Quiz filter theo FieldId
   - Quiz có RecommendationQuestions và RecommendationAnswers
   - User chọn RecommendationAnswer → Lưu vào RecommendationUserAnswer
4. Tính điểm career recommendation:
   - RecommendationUserAnswer join AnswerCareerWeight (bảng trọng số)
   - Tính tổng điểm cho từng Career
   - Lưu kết quả vào QuizCareerRecommendation (TOP 3 careers)
5. KHÁM PHÁ CAREERS:
   - Hiển thị TOP 3 careers với % match + Career Cards
   - Mỗi Career Card có 2 nút: "Learn Now" và "Details"
   - User có thể xem các career khác tương tự
6. BẮT ĐẦU HỌC (MULTIPLE LEARNING PATHS):
   - User bấm "Learn Now" → Tạo LearningPath cá nhân mới (nếu chưa có)
   - User có thể có NHIỀU learning paths cùng lúc
   - Progress tracking theo tree structure:
     * Topic complete khi xong hết LearningQuestions trong topic
     * Subject complete khi xong hết tất cả topics trong subject
7. HỌC THEO LEARNING PATH:
   - User xem learning path với progress tree (Subjects → Topics)
   - Hiển thị rõ: Đang học đâu, còn bao nhiêu phần, môn nào done
   - User bấm vào Topic → Làm LearningQuestions
   - User trả lời LearningQuestions → Lưu vào LearningUserAnswer
   - Hoàn thành Topic → Update progress tree
