SYSTEM FLOW (UPDATED - Định hướng chọn chuyên ngành)
-----------
1. User đăng ký → Login → Nhận JWT token
2. User làm Onboarding → Cập nhật UserType, MainGoal, FieldId
3. User làm Recommendation Quiz (theo FieldId của user):
   - Quiz filter theo FieldId
   - Quiz có RecommendationQuestions và RecommendationAnswers
   - User chọn RecommendationAnswer → Lưu vào RecommendationUserAnswer
4. Tính điểm career recommendation:
   - RecommendationUserAnswer join AnswerCareerWeight (bảng trọng số)
   - Tính tổng điểm cho từng Career
   - Lưu kết quả vào QuizCareerRecommendation (TOP 3 careers)
5. KHÁM PHÁ LEARNING PATHS (MỚI - TRƯỚC KHI CHỌN):
   - User xem learning path của TOP 3 careers được recommend
   - User có thể xem learning paths của TẤT CẢ careers trong field
   - User so sánh lộ trình học: subjects, topics, độ khó, thời gian ước tính
   - User xem chi tiết: mỗi subject gồm những topics nào, độ khó từng topic
6. RA QUYẾT ĐỊNH:
   - User chọn career phù hợp nhất dựa trên: % match + learning path + lương + sở thích
7. BẮT ĐẦU HỌC:
   - User tạo LearningPath cá nhân cho career đã chọn
   - User học theo Learning Path: Subjects → Topics → LearningQuestions
   - User trả lời LearningQuestions → Lưu vào LearningUserAnswer
   - Update UserProgress (tiến độ học tập)
